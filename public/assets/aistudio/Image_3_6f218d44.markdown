## Brand & Style

The design system establishes a high-performance, forward-looking aesthetic crafted to present advanced machine learning and artificial intelligence competencies to top-tier research labs, tech recruiters, and engineering leaders. The visual identity merges hyper-modern developer utility with sleek, polished futurism. 

### Design Principles
- **Algorithmic Precision:** Layouts and elements leverage mathematical proportion, meticulous rhythm, and modular structural alignments reminiscent of clean code and terminal aesthetics.
- **Luminous Depth (Deep Obsidian Glass):** Deep space backgrounds set the stage for translucent obsidian planes with crisp, light-emitting accents that evoke neural network activations and GPU compute environments.
- **Signal-to-Noise Purity:** The interface eliminates visual clutter. Visual cues are purposeful; neon gradients signify high-impact metrics, active states, and production-grade architectures.

### Tone & Demeanor
- **Tone:** Technical, authoritative, mathematically grounded, and elite.
- **Audience:** Machine learning research scientists, senior engineering directors, and talent acquisition teams evaluating high-leverage technical capability.
- **Emotional Response:** Immediate recognition of engineering caliber, clarity of deep-tech thought, and cutting-edge craft.

## Typography

The typographic hierarchy coordinates geometric modernity, body legibility, and technical code precision across three designated typefaces.

### Hierarchy Guidelines
- **Headlines (Plus Jakarta Sans):** Display titles leverage high-impact geometric tracking with tight character spacing (`letter-spacing: -0.02em` on hero and desktop sizes). Used for candidate credentials, project headlines, and categorical section titles.
- **Body & Editorial (Inter):** Applied across project abstracts, research overviews, methodology descriptions, and documentation notes. Set with open line-heights to ensure effortless technical reading on high-density displays.
- **Technical & Metric Metadata (JetBrains Mono):** Monospaced typography reinforces engineering rigor. Used for model architecture parameters (e.g., `params: 7B`, `latency: 14ms`), code snippets, terminal commands, directory badges, and runtime environment tags.
- **Overline Badges:** Displayed using `label-caps` with all-caps transformation and wide letter spacing (`letter-spacing: 0.12em`) above section headings to signal project domains (e.g., `COMPUTER VISION // PYTORCH`).

## Layout & Spacing

The layout model is anchored to a standard 12-column responsive fluid grid with strict max-width constraints on ultra-wide screens to maintain content readability.

### Viewport Breakpoints & Rules
- **Desktop (>= 1280px):** 12-column grid, max content boundary capped at `1280px`, horizontal canvas margin of `3rem`, column gutter of `1.5rem`.
- **Tablet (768px - 1279px):** 8-column layout, horizontal canvas margin of `2rem`, column gutter of `1.25rem`. Complex dual-column model cards adapt to single or staggered flows.
- **Mobile (< 768px):** 4-column layout, horizontal margin of `1.25rem`, gutter of `1rem`. Dense data tables convert into vertically stacked glass cards.

### Spacing Cadence
- Vertical component gaps follow an 8-point harmonic curve (`space-xs` = 4px, `space-sm` = 8px, `space-md` = 16px, `space-lg` = 24px, `space-xl` = 40px).
- Section intervals should be generous (`4rem` to `6rem`) to create clean division between distinct thematic blocks such as Featured Research, Benchmarks, Open Source Code, and Experience.

Visual hierarchy does not rely on traditional opaque drop shadows. Instead, depth is established through frosted glassmorphism, multi-stop radiant illumination, and fine-gauge luminous borders.

### Elevation Levels
- **Layer 0 (Canvas):** Pure `#060913` with subtle radial atmospheric gradient pools:
  - Atmospheric blur mesh: `radial-gradient(circle at 20% 20%, rgba(139, 92, 246, 0.08) 0%, transparent 50%), radial-gradient(circle at 80% 80%, rgba(6, 182, 212, 0.06) 0%, transparent 50%)`.
- **Layer 1 (Card & Section Containers):**
  - Surface: `background: rgba(10, 14, 26, 0.70)`.
  - Blur: `backdrop-filter: blur(12px) -webkit-backdrop-filter: blur(12px)`.
  - Edge: `border: 1px solid rgba(139, 92, 246, 0.18)`.
  - Shadow: `box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.36)`.
- **Layer 2 (Interactive Floating Modules / Active Cards):**

## Shapes

The geometric silhouette combines rounded contours (`roundedness: 2`) with structural edges. This curvature creates an approachable consumer-grade polish while avoiding excessive softness.

### Corner Radius Mapping
- Standard Inputs, Buttons, & Tags: `0.5rem` (8px).
- Project Cards & Benchmark Modules: `1rem` (16px).
- Modals, Hero Visual Shells, & Interactive Playgrounds: `1.5rem` (24px).
- Status Indicators, Micro Badges, & Avatar Rings: Fully circular / pill (`9999px`).
